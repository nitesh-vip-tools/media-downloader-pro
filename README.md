# VIP TOOLS — Media Downloader Pro

Colorful Termux CLI media downloader for video (MP4), audio (MP3), photos/thumbnails, and batch links.

**Developer:** Nitesh Yadav

## 1.  Termux Setup

```bash
termux-setup-storage && pkg update -y && pkg install -y git && git clone [https://github.com/nitesh-vip-tools/media-downloader-pro.git](https://github.com/nitesh-vip-tools/media-downloader-pro.git) && cd media-downloader-pro && bash install.sh
```

## 2. Run command

```bash
vipdl
```

## Menu Options
- `1` : MP4 Video Download
- `2` : MP3 Audio Download
- `3` : Photo / Thumbnail Download
- `4` : Batch Links Download
