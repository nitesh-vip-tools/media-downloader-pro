# VIP TOOLS — Media Downloader Pro

Colorful Termux CLI media downloader for video (MP4), audio (MP3), photos/thumbnails, and batch links.

**Developer:** Nitesh Yadav

## Install in Termux

```bash
pkg install -y git
git clone [https://github.com/nitesh-vip-tools/media-downloader-pro.git](https://github.com/nitesh-vip-tools/media-downloader-pro.git)
cd media-downloader-pro
bash install.sh
```

## Usage

```bash
vipdl
```
